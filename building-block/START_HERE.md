## 🆘 If You Get Stuck

### Unity Menu Missing "Multi-User VR"?
```
1. Check Console for errors
2. Assets > Reimport All
3. Restart Unity Editor
```

### Building Blocks Window Empty?
```
1. Wait for SDK import (check progress bar)
2. Window > Package Manager > Reimport Meta XR SDK
3. Restart Unity
```

### Validation Fails?
```
1. Check specific error in Console
2. See TROUBLESHOOTING in PHASE1_CHECKLIST.md
3. Re-run setup script
```
